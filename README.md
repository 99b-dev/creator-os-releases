# Creator OS

Markdown 문서와 폴더를 중심으로 콘텐츠를 기획하고 작성하는 Mac 작업실입니다.

[제품 소개](https://os.99b.co.kr/) · [다운로드 안내](https://os.99b.co.kr/download/)

## Mac 다운로드

[공개된 버전과 설치 파일 보기](https://github.com/99b-dev/creator-os-releases/releases)

Release가 아직 없다면 첫 정식 배포를 준비 중입니다. 게시된 버전의 **Universal `.dmg`** 파일을 받아 앱을 Applications 폴더로 옮기세요.

- macOS 13.3 이상
- Apple Silicon과 Intel을 하나의 설치 파일로 지원
- 정식 배포는 Developer ID 서명·Apple 공증과 업데이트 서명 검사를 거칩니다.

## 자동 업데이트

업데이트 기능이 포함된 정식 앱은 시작할 때와 실행 중 하루마다 새 버전을 확인하고 다운로드합니다. 작업을 저장한 뒤 앱 안의 **업데이트 후 재시작**을 누르면 적용됩니다. 앱이 꺼져 있었다면 다음 실행 때 확인합니다.

기존 개발 검수본(Preview)은 첫 정식 버전을 한 번 직접 설치해야 합니다. 문서 폴더는 앱 설치 파일과 별도로 보관됩니다.

`.app.tar.gz`, `.sig`, `latest.json`은 앱의 자동 업데이트용 파일입니다. 최초 설치에는 `.dmg`를 사용하세요.

이 저장소는 설치 파일·업데이트 파일·공개 변경 안내만 제공합니다. 소스 코드와 사용자 문서는 포함하지 않습니다.
